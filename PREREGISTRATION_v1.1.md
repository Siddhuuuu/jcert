## 1. Question and scope
Which aspects of a J-lens decomposition (selected support, J-space component, component readout) are sensitive to controlled numerical perturbations, and can that sensitivity be predicted from the clean decomposition beyond simple baselines?
**Scope: numerical sensitivity only.** Semantic faithfulness is NOT tested here; it needs a separate pre-registration (v2). A positive Stage 2 result would mean "predicts this numerical sensitivity", nothing more.

## 2. Fixed design
- Model `google/gemma-2-2b` through TransformerLens; lens artifact pinned as above. Gate 0 must show the library lens equals this artifact (G0.g).
- Activation: `blocks.{l}.hook_out`, clean fp32 forward pass, cached once. No extra centering or normalization.
- Source layers **{10, 13, 16, 19, 22}**: evenly spaced inside the band the nnsight tutorial maps from the paper's 38-92% depth (layers 10-24 of 26), excluding the last layers where the lens approaches the identity.
- Decomposition: `JacobianLens.decompose`, full-vocabulary library dictionary, **k = 25**, **algorithm = gradient_pursuit**.
- Prompts: **150** 64-token windows, **50 each** from wikitext-2-raw-v1 test, ag_news test and imdb test, chosen with seed 20261023, no duplicates. Positions: 4 per prompt, uniform from token indices 16-63, identical across layers. **Unit = (prompt, position, layer): 3000 units.**
  Sources are a stratification variable: results are reported per source as well as pooled. Overlap with the lens-fitting corpus is treated as an external-validity question (how typical are these activations), not a leakage threat, because a fixed dictionary's sensitivity to activation noise does not depend on whether a prompt was used to fit it. WikiText test articles should be disjoint from the WikiText train used for fitting (WikiText splits are article-disjoint; not verified here).
- **Primary perturbation: isotropic activation noise at a reference dose.** `delta = rho * ||h||_2 * u`, `u` uniform on the sphere, **M = 3** independent draws per unit, seeds derived from (prompt, position, layer, draw). This establishes sensitivity to isotropic noise at a scale tied to measured reduced-precision error. It does not establish sensitivity to real floating-point or quantization error, whose structure differs.
- **Reference dose rho_ref = clip(rho_med, 0.001, 0.03)**, where `rho_med` is the median of `||h_lowprec - h_fp32|| / ||h_fp32||` measured at Gate 0 (5 prompts x 3 positions x 5 layers; bf16, else fp16). Report `rho_med`, `rho_ref` and their ratio; if the ratio is not 1, the primary result must say the dose is that many times the measured error.
- **No dose escalation:** doses are fixed to the grid below; a null result is never rescued by a larger dose.
- Prompt list and fold assignment are generated by script from the seed; their hash is committed before any labels are computed.

## 3. Definitions
- `S(h)`: library `selected_support`. `P_S`: orthogonal projector onto the span of the (unit-normalized) lens vectors indexed by S. **Component** `c(h) = P_{S(h)} h`, the object the paper's interventions use per the library docs.
- **Primary metric:** `E(h, delta) = || P_{S(h+delta)}(h+delta) - P_{S(h)}(h+delta) || / || P_{S(h)} h ||`.
  Unchanged support implies `E = 0`. `E = 0` does NOT imply unchanged support (different supports can span the same subspace or project the vector identically).
- **Always report separately:** (i) fraction of units with unchanged `selected_support`; (ii) fraction with `E < 1e-6` (numerically zero); (iii) the distribution of `E`; (iv) absolute displacement `E_abs = ||Delta c|| / ||h||`; (v) baseline component fraction `f = ||P_S h||^2 / ||h||^2`, with `pi` also shown within tertiles of `f` (tiny components inflate relative `E`).
- Support metrics: **raw Jaccard is primary**. Conservative cluster Jaccard (strip space and `▁`, lowercase; tokens that normalize to empty are singleton classes) is reported alongside. Plural merging (drop a trailing "s" when length > 3) is a **sensitivity analysis only** because it over-merges (e.g. "class"/"clas").
- Readout metric `R` (secondary): Jaccard of the top-8 tokens of the **canonical lens readout** `softcap(lm_head(final_norm(J_l c)))` for `P_{S(h+delta)}(h+delta)` vs `P_{S(h)}(h+delta)`, using the pinned artifact's `J_l` and the model's own final norm. Gate 0 checks that this computation reproduces the tutorial's published top-1 tokens.
- Margin proxies: `m_gap` = minimum over pursuit steps of `(c1 - c2)/c1` (NNLS replay of the support order; approximate for gradient pursuit). `m_swap` = minimum over single swaps (remove j in S, add a from the 500 atoms most correlated with the residual) of the increase in squared projection residual over `||h||^2`.
- Baselines: B1 residual fraction `1 - f`; B2 `|S|`; B3 smallest atom contribution norm over `||reconstruction||`; B4 max |cosine| among selected atoms; B5 `m_gap`. Proposed features: J1 `log sigma_min` of unit atoms in S; J2 `m_swap`.
- Unit exclusion: empty selection or `||P_S h|| < 1e-8 ||h||`; counted and reported.

## 4. Gate 0: feasibility (5 prompts x 3 positions; no endpoint is computed)
Pass requires all of:
- G0.a: model and lens load; `decompose` runs at the five layers.
- G0.b: our projection matches the library's `j_space_component` (relative error < 1e-3); `reconstruction` equals the sum of coordinates times atoms; `E = 0` on identical supports.
- G0.c: peak GPU memory fits; median seconds per gradient-pursuit decomposition `t` and per-unit costs of J1, J2 and B5 are measured separately (CPU upper bounds are acceptable).
- G0.d: `rho_med`, `rho_ref` and the ratio are measured.
- G0.e (judgment call): library `fraction_of_variance` median >= 3% in at least 3 of 5 layers.
- G0.g (compatibility): (i) the TransformerLens hook activation equals the HF hidden state (relative diff < 1e-4); (ii) library dictionary rows have cosine >= 0.999 with rows of `W_U J_l` from the pinned artifact on 200 sampled tokens; (iii) the manual canonical readout reproduces at least 4 of the 6 published top-1 tokens of the tutorial prompt.
**Budget accounting (exact):** primary = 3,000 units x (1 clean + 3 draws) = 12,000 decompositions. Dose-response = 300 units (seeded, stratified over layers and sources) x 5 doses {0.1%, 0.3%, 1%, 3%, 10%} x 3 draws = 4,500 perturbed decompositions (clean ones reused). Total 16,500, plus feature computation (J1, J2, B5) on the 3,000 clean units. If `16,500 * t + 3,000 * t_feature` exceeds 5 GPU-hours: halve prompts once (to 75), then positions to 2, then layers to {13, 19}; never below 60 prompts; else stop. Estimates before measurement are extrapolations and may be far off.
Failure of G0.a-d or G0.g: stop and log. Failure of G0.e: report and decide manually (log a deviation).
After Gate 0, append a dated addendum with `rho_med`, `rho_ref`, `t`, feature costs, final unit counts and hashes, **before any Stage 1 computation.**

## 5. Stage 1: primary endpoint and decision rule (fixed sample, no extension)
**Primary endpoint:** `pi` = fraction of non-excluded units whose median-over-draws `E` at `rho_ref` exceeds **0.10**.
Why 0.10 (judgment call): a change of at least 10% of the component's own norm, caused purely by reselecting atoms, is the smallest change we would call material for an object that interventions edit. Also report `pi` at 0.05 and 0.20.
Why this endpoint: if immaterial noise changes which atoms define the component beyond its linear response, component-based readouts and interventions depend on arbitrary selection details. It is a necessary-condition diagnostic, not evidence of trustworthiness.
Uncertainty: 95% percentile CI from 2000 bootstrap resamples of **prompts**, computed once on the fixed sample (no interim looks).
- **Continue to Stage 2** if `pi_hat >= 0.10` and the CI lower bound `>= 0.05`.
- **Stop the predictor experiment** if the CI upper bound `< 0.10`; write up "components are robust at this dose".
- **Inconclusive otherwise:** report as inconclusive and stop. Any further data requires a new pre-registered replication on fresh prompts, not an extension of this analysis.
- If `pi_hat > 0.90`, Stage 2 runs at the largest grid dose with `pi <= 0.90`, labelled "dose-shifted".

## 6. Stage 2: does a clean-decomposition score predict sensitivity?
- Label `Y = 1[median-over-draws E > 0.10]` per unit.
- Models: L2 logistic regression on standardized features. **BL** uses B1-B5; **PM** uses B1-B5 + J1 + J2.
- **Nested validation:** outer 5-fold cross-validation grouped by prompt. Within each outer-training set only, an inner 3-fold grouped CV chooses C from {0.01, 0.1, 1, 10}. Feature standardization and all fitted preprocessing are fit on the outer-training prompts only; outer-test prompts never influence any choice.
- Statistic: `dAUROC = AUROC(PM) - AUROC(BL)` on pooled out-of-fold predictions. The 95% CI is a prompt-level bootstrap of those pooled predictions (it conditions on the fitted pipelines and is narrower than a full refit-the-pipeline interval; say so). Also repeat the whole cross-validation with 10 different fold seeds and report the spread. Report PR-AUC, Brier score and a reliability plot.
- **Supported** iff `dAUROC >= 0.03` and the CI lower bound `> 0`. The 0.03 floor is a judgment call (roughly the smallest gain worth the extra swap-margin cost); readers can apply their own bar from the CI.
- If AUROC(BL) >= 0.95, report a ceiling effect and call the effect-size test inconclusive.

## 8. Interpretation table and stopping rules
| Support under noise | Component under noise | Reading |
|---|---|---|
| changes | stable | atoms look interchangeable; token-level explanations unstable, aggregate robust |
| stable | changes | selected directions or coefficients are sensitive |
| changes | changes | instability at both levels |
- **Stage 2 fails (PM does not beat BL):** report that simple baselines explain the sensitivity; do not engineer a more complex score. A new score is exploratory and needs a new pre-registration.
- **Instability absent:** stop; publish the negative result and the tool.
- Support-level results never substitute for the primary component endpoint.
